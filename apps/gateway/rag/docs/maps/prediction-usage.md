물성 예측 화면은 오스테나이트계 스테인리스강을 대상으로 학습된 모델을 쓴다. 입력을 채우고 "사전학습 모델로 예측"을 누르면 결과 탭에 물성 4종이 평균과 불확실도(±)로 표시된다. Ctrl+S로 현재 예측 결과를 분석 기록에 저장할 수 있고, 파일 메뉴에서 분석 기록을 저장·불러오기 할 수 있다.

합금 조성(wt%) 입력 항목과 의미:
- Fe(철): 주 성분. 다른 원소를 넣으면 나머지로 자동 계산된다. 보통 60~70 wt% 이상.
- C(탄소): 강도를 높이지만 내식성을 낮춘다. 스테인리스강에서는 0.03~0.15 wt% 수준.
- Si(규소): 탈산제, 고온 내산화성 향상. 통상 0.3~1.0 wt%.
- Mn(망간): 오스테나이트 안정화 원소. 일반적으로 1.0~2.0 wt%.
- P(인), S(황): 불순물. 인은 취성, 황은 열간 가공성 저하를 일으켜 각각 0.045, 0.03 wt% 이하로 관리한다.
- Ni(니켈): 오스테나이트 안정화 핵심 원소. 300계열 기준 8~12 wt%.
- Cr(크롬): 부동태 피막을 만들어 내식성을 주는 핵심 원소. 16~18 wt% 수준.
- Mo(몰리브덴): 공식(pitting) 내식성 향상. SUS316 기준 2~3 wt%.
- Cu(구리): 내식성·가공성 향상. 보통 0~3 wt%.
- V(바나듐): 탄화물로 강도 향상. 0.1~0.5 wt%.
- N(질소): 고용강화와 오스테나이트 안정화, Ni를 일부 대체. 0~0.25 wt%.
- Nb(니오브), Ti(티타늄): 탄소를 탄화물로 고정해 입계부식(예민화)을 막는다. Nb 0.01~0.1, Ti 0.01~0.4 wt%.
- B(붕소): 열간 가공성 개선, 0.001~0.005 wt% 미량. Al(알루미늄): 탈산·내산화성, 0.01~0.05 wt%.

자동 계산 지표:
- Ni 당량 = Ni + 30×C + 0.5×Mn + 30×N + 0.3×Cu. 클수록 오스테나이트가 안정하다.
- Cr 당량 = Cr + Mo + 1.5×Si + 0.5×Nb. 클수록 페라이트(또는 마르텐사이트) 경향이 크다.
- Cr/Ni 비율 = Cr 당량 / Ni 당량. Schaeffler 도표에서 조직을 예측할 때 쓴다.
- C+N(침입형 원소 합): 클수록 항복강도가 오르고 내식성은 나빠질 수 있다.

공정·조직 입력:
- 고용화 열처리 온도(K): 탄화물을 기지에 다시 녹이는 온도. 일반적으로 1323~1423 K(1050~1150 °C).
- 고용화 열처리 시간(초): 보통 1800~7200초(30분~2시간). 두꺼운 제품일수록 길다.
- 냉각 방식: 수냉 등 열처리 후 냉각 방법.
- 결정립 수(mm⁻²): 클수록 결정립이 미세하고 강도·인성이 오른다.
- 용해 방식(0=전기로 EAF, 1=유도용해, 2=AOD, 3=VOD 등), 잉곳 크기(mm), 제품 형상(0=판재, 1=봉재, 2=관재, 3=단조품 등)은 정수 코드다.
- 시험 온도(K): 물성을 측정한 온도. 상온은 298 K.
