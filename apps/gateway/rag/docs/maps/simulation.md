시뮬레이션 화면은 왼쪽 합금 관리, 가운데 3D 뷰, 오른쪽 예측 결과, 아래 타임라인으로 나뉜다.

합금 관리(왼쪽): "새 합금"으로 합금을 추가하고 검색·삭제한다. 재질 조성 비율 슬라이더로 원소 비율을 바꾸고 "원소 추가"로 원소를 넣는다. 조성 합계가 100%여야 정상이다. "예측 결과 가져오기"로 JSON·Excel·CSV 파일이나 GitHub raw/API URL에서 합금 목록을 불러올 수 있다.

3D 뷰(가운데):
- 보기 모드: 열 분포, 응력 분포, X-Ray, 와이어프레임, 모델 비교. "초기화"는 뷰를 처음 상태로 돌린다.
- 조작: 시편, 카메라 이동, 변형 테스트.
- 시험: "강도 테스트"(인장)와 "휘어짐 테스트"(굽힘). 왼쪽 위 σ_VM 범례는 폰 미세스 응력 색 단계이고 항복강도(YS) 위치가 표시된다. 오른쪽 위에 응력 최대치, 왼쪽에 온도 분포, 아래에 변형률이 나온다.
- 파단: 시험이 끝나면 파단 모드에 맞는 파면을 보여준다. 연성은 가운데 딤플(섬유상) 영역과 바깥 45° 전단 립이 있는 컵-앤드-콘, 취성은 평평한 벽개 파면, 그 사이는 혼합형이다.

예측 결과(오른쪽): 0.2% 항복강도, 인장강도(UTS), 연신율, 단면수축률. "상·결정구조(Schaeffler)"는 Ni 당량·Cr 당량(WRC-1992)으로 예상 조직(예: 오스테나이트+페라이트)과 상 비율(γ-FCC, α-BCC, α'-BCT)을 보여준다. "격자 뷰어"는 주된 결정구조(예: FCC)의 원자 배열을 3D로 보여준다. 그 아래 온도 분석과 응력-변형률 그래프가 있다.

타임라인(아래): 재생·재생 속도와 열 이벤트, 응력 피크, 변형률 수렴 같은 사건 표시.

위쪽 버튼과 파일 메뉴: CSV 내보내기, JSON 내보내기, 상태 저장, 대시보드 결과 저장소에 저장, 보고서 생성(재료 시험 보고서 PDF). "← 대시보드"로 대시보드로 돌아간다.
